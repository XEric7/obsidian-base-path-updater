## 新增

- 可在插件设置中打开「更新 Markdown 中的 Base」。打开后，文件夹移动或重命名时会更新笔记里的 `base` 代码块。该开关默认关闭。
- Markdown 中的嵌入 Base 按代码块撤回，笔记其余修改会保留。相同围栏会用旁边的文字区分；无法确定是哪一块时记为冲突，不猜测修改位置。
- HTML 注释，以及 `script`、`pre`、`style`、`textarea` 中的围栏不会被改写。

## 升级说明

历史格式保持 v2，兼容现有历史记录。升级后 Markdown 更新默认关闭，需要时在插件设置中打开。

下载 `main.js`、`manifest.json` 和 `styles.css`，放入仓库的 `.obsidian/plugins/base-path-updater/` 并重新启用插件。
