## 新增

- 中英文界面跟随 Obsidian 语言设置，覆盖命令、菜单、设置、通知和历史窗口。
- Obsidian 1.13+ 设置搜索支持中英文关键词，继续兼容 Obsidian 1.9.0+。
- 历史中的插件错误按当前界面语言显示；未知系统或第三方错误保留原文。
- 推送版本 tag 后，GitHub Actions 自动检查、构建、生成产物证明并发布安装附件。

## 修复

- 修复禁用或重载插件时，旧实例继续保存并覆盖新实例历史的问题。
- 修复超大 Base 被跳过时，已有撤回记录仍被提前淘汰的问题。

## 升级说明

历史格式升级为 v2，自动兼容读取 v1 历史；文件快照和撤回保护保持不变。保存为 v2 后，旧版插件无法读取该历史。

下载 `main.js`、`manifest.json` 和 `styles.css`，放入仓库的 `.obsidian/plugins/base-path-updater/` 并重新启用插件。
